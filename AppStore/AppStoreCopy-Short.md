# Scanny, short App Store copy

Same submission, shorter text. For people skimming search results, not reading
a pitch. See `AppStoreCopy.md` for the rest of the fields (keywords, URLs,
review notes, etc.), only Promotional Text and Description differ here.

**Promotional Text**, max 170 chars.
```
Scan documents to clean, searchable PDFs. Free, no ads, no account. Everything stays on your iPhone.
```

**Description**, max 4000 chars, but short on purpose.
```
Scan documents into clean, searchable PDFs.

• Camera or import photos, auto-crop, auto-straighten
• Color, grayscale, or B&W scanner look
• Searchable text (OCR)
• Share or AirDrop the PDF

100% on-device. No account, no ads, no subscriptions, no tracking. Free.
```
